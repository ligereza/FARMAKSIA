# Dimensiones del Orden - working submission dossier

This is a working, auditable dossier for the **Produccion de obras experimentales, Fondo Audiovisual 2027**. It prepares, but does not replace, the official FUP. No local PDF or copy block proves that an application was submitted; platform fields, dates, region, rights, venue, budget and receipt remain to be confirmed.

The canonical framing is a live generative audiovisual work. Sound and geometric fixture layout are compositional variables; LED surfaces and physical luminaires are material light sources in the same audiovisual field. Blender/Geometry Nodes provides a procedural reference and the live layer tests how it changes through real installation, capabilities, protocols, latency and discretization. Mapping, semantic control and interoperability are bounded instruments and development ambitions, not a proven universal product or autopatcher. The existing Blender scene and MP4 are real artistic/technical antecedents; multi-device installation and cross-backend translation remain experiments unless a run record proves otherwise. OUTWORLD is an aesthetic reference only.
