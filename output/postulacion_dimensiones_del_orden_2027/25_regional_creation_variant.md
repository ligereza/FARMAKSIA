# Regional creation variant

## Working title

Luz entre sistemas: instalacion generativa de una arquitectura luminosa

## Status

This is an adaptation draft for Fondart Regional 2027, Creation: Innovation and New Creative Formats. It is not the canonical audiovisual application and must not be sent without a confirmed region, venue and public exhibition plan.

## Project statement

The project creates a site-specific luminous installation in which LED surfaces and physical luminaires form a spatial field rather than a screen that merely plays back an image. A procedural rule generated in Blender and executed through a live control layer transforms phase, tempo, energy, density, direction and distance into light. The work observes the real venue, models its positions and uses that geometry to compose the propagation of light.

The venue is not a neutral container. Its scale, walls, sight lines, power, audience path and existing light conditions modify the work. The installation becomes a temporary instrument that reveals how a mathematical relation changes when it encounters a real architecture and a heterogeneous set of devices.

## Objectives

- Create and exhibit a site-specific luminous installation in a real regional venue.
- Translate one procedural light state into LED surfaces and a bounded set of physical luminaires.
- Make the venue layout part of the composition through an explicit spatial graph.
- Produce a public encounter in which viewers can perceive the relation between sound, surface light, beams and architecture.
- Preserve a technical and artistic process document that records the installation, decisions, deviations and public presentation.

## Method

The project proceeds through design, layout observation, mapping, soundcheck, live composition and public exhibition. The mapping stage establishes a relation between physical positions and logical nodes. The patch stage establishes the relation between logical nodes, fixture profiles and control addresses. These stages remain visible and are not presented as silent automation.

The common state is expressed as:

`S(t) = {phase, tempo, energy, density, direction, topology, palette, transition}`

Audio changes the temporal state through measured amplitude, transients, silence and controlled transitions. The same state is interpreted by the LED surface and physical luminaires according to their actual capabilities. If a device cannot express a dimension, the loss is recorded as part of the work.

## Final result

- One installed and publicly exhibited luminous work.
- One audiovisual record of the installation and public encounter.
- One layout and mapping profile for the selected venue.
- One process document with parameters, versions, tests, failures and decisions.

## Scope decision

The regional version uses one venue, one bounded device configuration and one exhibition period. It does not promise a universal installation service or a commercial autopatcher. Camera-assisted mapping, RDM and active probes are experimental instruments whose use depends on the selected equipment.
