# Curriculum evidence map

This document is an internal map for the curriculum section of the
`Dimensiones del Orden` application. It does not invent dates, awards,
clients, publications, or public deployment. Each item remains a candidate
until the applicant confirms the corresponding profile or attachment.

## How to use this map

The curriculum criterion should show that the applicant can execute the
proposed work: procedural audiovisual production, live visual systems,
signal-oriented programming, and technical documentation. It should not turn
the application into a catalogue of every project in the ecosystem.

The selected evidence should be presented as a small set of representative
works and technical practices. Source repositories are proof of development
activity; they are not by themselves proof of public exhibition, authorship,
commercial delivery, or institutional recognition.

## Recommended curriculum selection

Use a compact evidence chain rather than listing all repositories:

`procedural audiovisual work` -> `technical process and rule encoding` ->
`live visual and signal practice` -> `physical translation and documentation`.

The primary item should be the existing audiovisual work and its Blender
source. MOSAIK and XIO should function as supporting technical context only if
the applicant can connect them to actual prior practice and provide a date,
work sample, or other admissible evidence. Do not present the proposed BLE
multi-device installation as already completed.

## Evidence packet to prepare

- One still or short excerpt from the existing audiovisual work.
- One concise technical description of the Geometry Nodes and camera-phase
  process.
- One dated project or work record demonstrating live visual practice, if
  available.
- One dated record demonstrating signal, cue, timecode, or hardware workflow,
  if available.
- A short statement distinguishing what already exists from what the grant
  will test and produce.

## Editorial rule

The curriculum section must answer: “Why can this applicant execute this
experiment?” It should not answer: “How many tools has this ecosystem
accumulated?” The latter belongs in internal development notes, not in the
application.
