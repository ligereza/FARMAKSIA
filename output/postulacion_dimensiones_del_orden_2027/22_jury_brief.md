# Jury brief

## One-sentence proposal

`Dimensiones del Orden` is an experimental live audiovisual work that translates
one deterministic spatial-temporal light rule between procedural 3D, LED
surfaces and heterogeneous lighting systems, making the difference between
intention, interface and physical execution part of the artwork.

## Why this is an experiment

The project does not ask whether a wireless system can imitate a render in the
abstract. It freezes one mathematical state, reconstructs the physical layout,
verifies the relation between position and patch, translates the state through
available protocols, and records where the correspondence survives or breaks.
The break is not hidden as a technical failure; it becomes material for the
audiovisual result and the process document.

## What already exists

- A procedural Blender scene with Geometry Nodes and a verified complete camera
  loop from frames 300-790.
- A 491-frame audiovisual record at 30 FPS that matches that loop.
- Code evidence for controlling one BLE device with GATT, audio and BPM
  inputs.
- A documented mathematical and procedural basis for phase, pulse, angle and
  spatial order.
- A reproducible method for comparing reference phase, visible onset, order,
  drop rate and repeated runs.

## What the grant enables

- A controlled one-device baseline and geometric layout template.
- A multi-device physical configuration with explicit device identities and
  mapping evidence.
- Preshow discovery, soundcheck verification and live translation stages.
- Perturbed runs with delay, jitter, wrong patch or dropped updates.
- A comparison between native control and the common semantic state.
- A recorded comparison between simulation and physical output.
- A finished audiovisual work and a process document that preserves rules,
  versions, measurements, failures and decisions.

## Why the project is executable

The proposal begins with a known procedural scene and an existing single-device
control antecedent. It does not assume that the hardest configuration already
works. The schedule isolates protocol and mapping risk before adding spatial
complexity, and the budget is tied to devices, installation, testing,
recording and documentation rather than generic software development.

## What the project does not claim

It is not a commercial lighting controller, a replacement for grandMA or
Avolites, a universal autopatcher, a clinical study, or proof of a universal
perceptual threshold. It does not present multi-device synchrony or
cross-console interoperability as an existing result. The application funds
the test that can produce correspondence, degradation, divergence, or all
three.
