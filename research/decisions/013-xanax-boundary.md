# Decisión 013 — X-ANA-X sobrevive como contrato, no como salida observable

Fecha: 2026-08-23

## Evidencia

El experimento 008 separó entradas, preguntas, observables, representaciones y
autoridad. Sin `events.json`, la consulta temporal no está disponible. Con la
entrada externa, X-ANA-X puede cambiar el observable a intersección activa;
KETAMINE después puede materializar el estado temporal.

Algunas rutas distintas producen `left-region`, pero sus firmas de contrato no
coinciden. La respuesta por sí sola no identifica el operador.

## Decisión

X-ANA-X queda provisionalmente como un contrato explícito para cambiar el
espacio de preguntas, observables, estados o entradas. No se acepta como una
teoría nueva por el simple hecho de cambiar una consulta: eso puede ser
reformulación conocida. Tampoco se atribuye el tiempo a una conversión pura de
SVG cuando la procedencia exige `events.json`.

## Kill test

Pasa el kill test estrecho “crear temporalidad sin entrada temporal”: no puede
responderse. No pasa todavía un kill test de novedad conceptual: la misma
conducta puede describirse con reformulación, state augmentation o
materialización temporal conocida.

## Próximo paso

Aplicar el contrato a una obra creativa autorizada con una pregunta cuya
reformulación cambie una decisión posible y cuyo residuo no pueda describirse
solo como una vista, índice o consulta adicional. Si no aparece esa propiedad,
X-ANA-X debe fusionarse con reformulación/state augmentation.
