# Investigación 007 — analogía, búsqueda y vibecoding

Fecha: 2026-08-23

## Pregunta

¿Puede X-ANA-X estudiar una experiencia real de no entender, usando analogías
y búsqueda computacional, sin reducirse a metáforas decorativas?

## Analogía como mecanismo

La teoría de Structure-Mapping describe la analogía como alineamiento de
relaciones, no como coincidencia de atributos superficiales. La evidencia
neurocognitiva sitúa el razonamiento analógico en una red frontoparietal, con
un papel consistente de la corteza prefrontal rostrolateral en la integración
relacional:

- https://pubmed.ncbi.nlm.nih.gov/27012301/
- https://pubmed.ncbi.nlm.nih.gov/15238433/
- https://pmc.ncbi.nlm.nih.gov/articles/PMC6293195/

Para FARMAXIA, una analogía útil debe declarar:

- dominio fuente y dominio objetivo;
- entidades y roles correspondientes;
- relaciones que se conservan;
- atributos que se ignoran o deforman;
- inferencia nueva que se intenta transportar;
- predicción verificable;
- condición de ruptura.

Una analogía no está validada porque sea clara o tranquilizadora. Está
validada cuando permite predecir o explicar correctamente una propiedad del
objetivo que no estaba explícita.

## X-ANA-X y búsqueda en computador/web

La búsqueda no es una analogía, pero puede ser el mecanismo que encuentra el
dominio fuente. Information Foraging Theory modela la búsqueda mediante
“information scent”: señales locales que estiman el valor de continuar en un
parche de información:

- https://onlinelibrary.wiley.com/doi/10.1207/s15516709cog0000_20
- https://www.oxfordacademic.com/book/7603

La cadena de X-ANA-X puede ser:

`no entiendo → formular laguna → buscar fuente → seleccionar estructura → mapear → probar → abandonar o conservar`

La consulta web, el resultado, la autoridad de la fuente y la razón para
seleccionarla deben quedar registrados. Buscar más no equivale a entender más.

## Relación con vibecoding

El vibecoding es relevante como caso de estudio de delegación conversacional:
el humano expresa intención de alto nivel y el modelo genera o modifica un
artefacto. Esto puede reducir la fricción de implementación, pero abre una
brecha entre:

`intención humana → código generado → comportamiento observado → comprensión humana`

La investigación reciente sobre el término lo describe como una práctica
conversacional y señala riesgos de fragmentación cognitiva y de artefactos que
parecen maduros antes de ser comprendidos:

- https://doi.org/10.1515/icom-2026-0018
- https://arxiv.org/abs/2601.02410

X-ANA-X no debe estudiar “si el modelo escribe código”, sino si la cadena de
analogías, búsquedas y delegaciones conserva el modelo mental necesario para
verificar el resultado.

## Prototipo mínimo

Usar un problema pequeño pero real del repositorio y producir tres rutas:

1. explicación directa;
2. explicación mediante una analogía explícita;
3. búsqueda web + analogía + verificación.

Registrar para cada paso: tiempo, preguntas, fuente, mapeo, predicción,
resultado de prueba, corrección posterior y punto de ruptura. El kill test es
que una analogía aumente la confianza o la velocidad, pero empeore la
transferencia, la detección de errores o la explicación posterior.
